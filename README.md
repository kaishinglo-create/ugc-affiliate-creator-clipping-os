# UGC Affiliate Creator Clipping OS

A standalone workspace for affiliate opportunity research, creator campaigns, UGC scripts, authorized video clipping, content planning, and performance tracking. **No CarryOS dependency.**

## Run locally

Requirements: Node.js 18+.

```bash
npm run start
```

Open http://localhost:4173. No third-party runtime dependencies are required for this initial UI foundation.

## Current status

The initial build provides a responsive interactive dashboard and local demo records. AI providers, video processing, YouTube/affiliate/publishing APIs, persistent storage, and real analytics are not connected yet. Demo values are illustrative.

See [MASTER_PROMPT.md](MASTER_PROMPT.md), [architecture](docs/ARCHITECTURE.md), and [autonomous build state](docs/autonomous-build/STATE.md).
