# UGC Affiliate Creator Clipping OS

Standalone application (no CarryOS dependency) for UGC affiliate creator workflows.

## Stack
- Node 22+ / TypeScript
- Fastify
- Vitest

## Scripts
- `npm run dev` - dev server
- `npm run build` - compile
- `npm run typecheck` - typecheck
- `npm test` - tests
- `npm run lint` - lint (not yet configured)
